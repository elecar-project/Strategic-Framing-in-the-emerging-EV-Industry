結果解讀

研究結果顯示，資料處理與切分方式會影響可辨識的主題數、離群比例與主題集中程度。主模型的 LLM 重複命名結果可協助辨識較具一致性的主題名稱；名稱一致性較低的主題則應結合代表文本進行人工判讀。

指標說明：有效主題數代表排除離群資料後的群集數；離群比例代表未被歸入有效主題的文本比例；最大主題比例反映主題是否過度集中；平衡分數綜合離群比例、主題數與集中程度，僅用於同一研究設計下的比較。
